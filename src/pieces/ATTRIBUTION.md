# Piece artwork

The twelve piece SVGs in this directory are the Cburnett chess set, the standard set used by
Lichess and Wikipedia.

- **Author:** Colin M.L. Burnett (Cburnett)
- **Source:** [Wikimedia Commons, SVG chess pieces](https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces)
- **Licence:** [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

CC BY-SA requires attribution and that derivatives keep the same licence. The files here are
unmodified. This file is the attribution; do not delete it when moving the assets.

The files are unmodified and loaded as decorative images; the board gridcell provides the
accessible piece name.
